🚀 REST API Endpoints

🏀 Game Management

GET /api/games/all Retrieve all games
GET /api/games/{id} Get specific game by ID
GET /api/games/team/{teamId} Get games for specific team
POST /api/games Create new game
PUT /api/games/{id} Update entire game
PATCH /api/games/{id} Partially update game
DELETE /api/games/{id} Delete game

👥 Team Management

GET /api/teams/all Retrieve all teams
GET /api/teams/{id} Get specific team
POST /api/teams Create new team

🔐 Authentication

GET /oauth2/authorization/google Google OAuth2 login
GET /oauth2/authorization/github GitHub OAuth2 login
POST /api/auth/mobile/login JWT mobile authentication
