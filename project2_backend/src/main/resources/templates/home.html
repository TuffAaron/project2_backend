Project2 Backend OAuth2 Demo

Welcome to your Spring Boot OAuth2 application! This demo showcases OAuth2 integration with GitHub and Google.

Features Available:

  • OAuth2 Authentication with GitHub and Google
  • Spring Security Integration
  • User Profile Management
  • NBA Games & Teams API (Protected Routes)
  • H2 Database Console Access
  • RESTful API Endpoints

Quick Actions:

Login with OAuth2 Test Public API Database Console

API Endpoints:

  • Public: /api/public/status - No authentication required
  • Protected: /api/user - Requires authentication
  • Games API: /api/games/** - Requires authentication
  • Teams API: /api/teams/** - Requires authentication
